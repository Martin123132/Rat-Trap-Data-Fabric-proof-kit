# Rat-Trap v0.2 Evidence Packaging Backlog

The next product milestone is not a larger benchmark. It is turning the proof
workflow into a cleaner buyer artifact that is easy to run, verify, and explain.

## Priority 1

- Add a first-class proof verifier that checks a proof ZIP, recomputes its
  SHA-256, confirms required artifacts, validates `.gmw`, and prints a concise
  pass/fail receipt.
- Improve `enterprise-proof-summary.md` so Proof #1 and Proof #2 can be read
  without opening JSON.
- Add a one-cell Colab helper that embeds the standalone runner logic directly
  and never asks for a GitHub token.

## Priority 2

- Add a conservative ROI report mode that turns logical bytes, archive bytes,
  restore results, and user-supplied storage price into monthly and yearly
  estimates.
- Add optional zlib versus zstd comparison in proof output when zstandard is
  installed, while keeping zlib-only fallback for plain Colab runs.
- Add a combined buyer proof report that accepts Proof #1 and Proof #2 ZIPs and
  writes a single Markdown/PDF-ready narrative.

## Acceptance

- A nontechnical buyer can open one report and understand source provenance,
  compression, dedupe, validation, restore, streaming, and limitations.
- A technical buyer can verify every headline number from JSON artifacts inside
  the ZIP.
- Money claims remain opt-in and parameterized; cloud storage pricing must be
  checked against official provider pages before quoting externally.
